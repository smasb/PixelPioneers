# Pixel Pi-oneers website

A static HTML, CSS and JavaScript website ready for GitHub Pages.

## Included
- `index.html` — all website sections and content
- `style.css` — responsive styling
- `script.js` — mobile navigation, animations and mini quiz
- `assets/` — official team logo and optimized original photos extracted from the supplied portfolio

## Publish / update GitHub Pages
1. Extract this ZIP.
2. Upload the contents of this folder to the root of your existing GitHub repository.
3. Replace the old `index.html`, `style.css` and `script.js`.
4. Upload the entire `assets` folder and allow GitHub to replace the old assets.
5. Commit the changes. GitHub Pages will republish automatically.
